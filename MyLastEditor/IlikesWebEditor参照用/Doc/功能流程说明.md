# MyLastEditor 功能流程说明

---

## 一、页面加载流程

### 打开页面时执行：
```
1. 初始化数据库（如果不存在则创建）
2. 初始化 ACE 编辑器
3. 加载编程语言列表
4. 设置默认语言为 JavaScript
5. 显示空白的编辑界面
```

---

## 二、保存内容流程

### 点击「保存内容」按钮时：

**情况 1：新建模式（未加载任何内容）**
```
1. 验证必填字段（标题、内容、语言）
2. 收集所有表单数据
3. 发送 AJAX 请求到后端 SaveContent 方法
4. 后端创建新记录，保存到数据库
5. 返回新记录的 ID
6. 前端提示："内容保存成功！ID: xxx"
7. 清空所有输入框
8. 重新加载内容列表
```

**情况 2：更新模式（已加载某条内容）**
```
1. 验证必填字段（标题、内容、语言）
2. 收集所有表单数据 + 当前编辑的 ID
3. 发送 AJAX 请求到后端 SaveContent 方法
4. 后端根据 ID 找到原记录
5. 更新原记录的所有字段
6. 返回更新的 ID
7. 前端提示："内容更新成功！ID: xxx"
8. 清空所有输入框
9. 重置编辑状态（currentEditingId = null）
10. 重新加载内容列表
```

---

## 三、加载内容流程

### 点击「加载列表」按钮时：
```
1. 发送 AJAX 请求到后端 GetAllContents 方法
2. 后端查询所有内容，按创建时间倒序排列
3. 返回内容列表（JSON 格式）
4. 前端解析 JSON 数据
5. 生成 HTML 表格，显示所有记录
6. 绑定「加载」和「删除」按钮事件
```

### 点击某条记录的「加载」按钮时：
```
1. 获取该记录的 ID
2. 发送 AJAX 请求到后端 LoadContent 方法
3. 后端根据 ID 查询单条记录
4. 返回完整的记录数据（JSON 格式）
5. 前端解析 JSON 数据
6. 填充所有表单字段：
   - 标题 → #contentTitle
   - 副标题 → #contentSubtitle
   - 作者 → #contentAuthor
   - 热门标签 → #contentHotTags
   - 分享给 → #contentShareTo
   - 语言 → #languageSelect
   - 代码内容 → 编辑器
7. 记录当前编辑的 ID（currentEditingId = 内容 ID）
8. 提示："内容加载成功！"
```

---

## 四、删除内容流程

### 点击某条记录的「删除」按钮时：
```
1. 弹出确认对话框："确定要删除这个内容吗？"
2. 用户确认后，获取该记录的 ID
3. 发送 AJAX 请求到后端 DeleteContent 方法
4. 后端根据 ID 删除记录
5. 返回成功消息
6. 前端重新加载内容列表
7. 提示："内容删除成功！"
```

---

## 五、关键状态管理

### currentEditingId 变量

| 值 | 含义 | 保存时的行为 |
|----|------|-------------|
| `null` | 新建模式 | 创建新记录 |
| `数字` | 更新模式 | 更新该 ID 的记录 |

**状态变化：**
```
页面加载 → currentEditingId = null（新建模式）
加载内容 → currentEditingId = 内容 ID（更新模式）
保存成功 → currentEditingId = null（回到新建模式）
```

## 六、数据流向图

```
前端（浏览器）                    后端（服务器）
─────────────                    ─────────────

[保存内容]
   │
   ├─→ 收集表单数据
   │
   ├─→ AJAX POST ───────────────→ SaveContent 方法
   │                               │
   │                               ├─→ 判断是否有 ID
   │                               │   ├─ 有 ID → UpdateContent
   │                               │   └─ 无 ID → InsertContent
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {success: true, id: 123}
   │
   └─→ 显示提示 + 清空表单


[加载内容]
   │
   ├─→ 获取内容 ID
   │
   ├─→ AJAX POST ───────────────→ LoadContent 方法
   │                               │
   │                               ├─→ 查询数据库
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {title, content, ...}
   │
   └─→ 填充表单 + 设置编辑器


[删除内容]
   │
   ├─→ 获取内容 ID
   │
   ├─→ AJAX POST ───────────────→ DeleteContent 方法
   │                               │
   │                               ├─→ 删除记录
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {success: true}
   │
   └─→ 刷新列表
```

## 七、核心文件职责

| 文件 | 职责 |
|------|------|
| **WebForm1.aspx** | 主页面，包含所有 UI 元素 |
| **EditorContentManager.js** | 处理保存、加载、删除的 JavaScript 逻辑 |
| **EditorPage.js** | 初始化编辑器和语言选择器 |
| **WebForm1.aspx.cs** | 后端 WebMethod 接口（SaveContent、LoadContent 等） |
| **EditorContent.cs** | 数据模型定义（EditorContent 类） |
| **EditorContentRepository.cs** | 数据库 CRUD 操作 |
| **InitializeDatabase.cs** | 数据库初始化 |

---

## 八、一句话总结

**页面加载** → 初始化一切  
**点击保存** → 判断是新建还是更新  
**点击加载** → 从数据库取数据并填充  
**点击删除** → 从数据库删除记录  

**关键机制**：通过 `currentEditingId` 变量区分新建和更新
