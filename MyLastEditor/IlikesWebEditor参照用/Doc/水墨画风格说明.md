# 🎨 三国 11 水墨画风格 - 界面设计说明

## 🖼️ 设计理念

融合**中国古典水墨画**与**三国 11 游戏**的美术风格，打造古风古色的代码编辑器界面。

---

## ✨ 核心特色

### 1. **宣纸质感**
```
背景色：#f4f0e6 (米黄宣纸色)
纹理：细密的十字布纹
晕染：多层次水墨渐变
```

### 2. **木质边框**
```
主框架：#8b7355 (深棕色)
次边框：#a08260 (浅棕色)
阴影：柔和的木纹投影
```

### 3. **楷体字体**
```
中文字体："KaiTi", "楷体", "STKaiti"
英文字体：衬线体
字号：偏大，彰显古韵
```

## 🏛️ 视觉元素

### 1. 背景效果

#### 宣纸纹理
```css
body::before {
    /* 十字布纹 */
    background: 
        repeating-linear-gradient(90deg, ...),
        repeating-linear-gradient(0deg, ...);
}
```

#### 水墨晕染
```css
body::after {
    /* 多层径向渐变 */
    background: 
        radial-gradient(circle at 30% 20%, rgba(0,0,0,0.05)...),
        radial-gradient(circle at 70% 60%, rgba(0,0,0,0.03)...);
}
```

### 2. 边框装饰

#### 木质边框
```css
.container {
    border: 3px solid #8b7355;
    border-radius: 8px;
    box-shadow: 
        0 10px 30px rgba(0, 0, 0, 0.15),
        inset 0 0 30px rgba(139, 115, 85, 0.1);
}
```

#### 渐变分割线
```css
.sidebar-header::after {
    background: linear-gradient(90deg, transparent, #8b7355, transparent);
}
```

### 3. 按钮设计

#### 印章风格按钮
