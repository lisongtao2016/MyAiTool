# 登录画面机能定义书

## 📋 画面概要

**画面名称**: 用户登录/注册画面  
**文件名**: `login.html`  
**用途**: 提供用户身份认证入口，支持新用户注册和已有用户登录

---

## 🎯 核心机能

### 1. 用户登录

#### 1.1 输入项
| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 用户名/邮箱 | 文本 | ✅ | 非空，3-100字符 |
| 密码 | 密码 | ✅ | 非空，最少6字符 |

#### 1.2 处理逻辑
```
1. 验证输入格式
2. 调用 WebServ.asmx/LoginUser
3. 后端验证：
   - 查询 Users 表（Username 或 Email）
   - 验证 PasswordHash（SHA256）
   - 检查 IsActive = 1
4. 成功：
   - 更新 LastLoginDate
   - 保存 userInfo 到 localStorage
   - 清除 lastRegisteredUser
   - 跳转至 WebForm1.aspx
5. 失败：显示错误提示
```

#### 1.3 输出
- **成功**: 跳转到主编辑器页面
- **失败**: 显示错误消息（用户名/密码错误、账户已禁用等）

---

### 2. 用户注册

#### 2.1 输入项
| 字段 | 类型 | 必填 | 验证规则 |
|------|------|------|----------|
| 用户名 | 文本 | ✅ | 3-20字符，唯一 |
| 邮箱 | 邮箱 | ✅ | 有效格式，唯一 |
| 显示名称 | 文本 | ❌ | 可选，最多100字符 |
| 密码 | 密码 | ✅ | 最少6字符 |
| 确认密码 | 密码 | ✅ | 与密码一致 |

#### 2.2 处理逻辑
```
1. 前端验证所有字段
2. 调用 WebServ.asmx/RegisterUser
3. 后端处理：
   - 检查 Username 唯一性
   - 检查 Email 唯一性
   - SHA256 加密密码
   - 插入 Users 表（Role='user', IsActive=1）
4. 成功：
   - 保存 lastRegisteredUser 到 localStorage
   - 切换回登录表单
   - 自动填充用户名和密码
   - 显示脉冲动画引导登录
5. 失败：显示错误（用户名/邮箱已存在）
```

#### 2.3 输出
- **成功**: 返回登录页并自动填充凭据
- **失败**: 显示具体错误原因

---

### 3. 智能填充

#### 3.1 注册后自动填充
- **触发条件**: 注册成功后
- **行为**: 
  - 保存凭据到 `localStorage.lastRegisteredUser`
  - 1.5秒后切换到登录表单
  - 自动填充用户名和密码
  - 显示蓝色提示框 + 脉冲动画

#### 3.2 再次访问自动填充
- **触发条件**: 页面加载时检测到 `lastRegisteredUser`
- **行为**:
  - 仅在输入框为空时填充
  - 显示黄色提示框
  - 不自动登录，等待用户确认

## 🔐 安全机制

### 密码处理
- **加密算法**: SHA256
- **存储方式**: 十六进制字符串（64字符）
- **传输方式**: HTTPS（生产环境）

### 会话管理
- **存储位置**: localStorage
- **关键字段**:
  - `userInfo`: 当前登录用户信息
  - `lastRegisteredUser`: 上次注册凭据

### 防护措施
- ✅ SQL 注入防护（参数化查询）
- ✅ 前端表单验证
- ✅ 后端业务验证
- ✅ 唯一性约束（Username, Email）

## 📡 API 接口

### LoginUser
```javascript
POST WebServ.asmx/LoginUser
{
  identifier: "用户名或邮箱",
  password: "明文密码"
}
响应: { success: true/false, message: "...", userId, username, ... }
```

### RegisterUser
```javascript
POST WebServ.asmx/RegisterUser
{
  username: "用户名",
  email: "邮箱",
  password: "明文密码",
  displayName: "显示名称（可选）"
}
响应: { success: true/false, message: "..." }
```

## 🔄 业务流程图

```
用户访问 login.html
    ↓
检测 localStorage.userInfo
    ↓ 存在
自动跳转 WebForm1.aspx
    ↓ 不存在
显示登录表单
    ↓
用户操作：
  ├─ 点击"立即注册" → 显示注册表单
  │     ↓
  │   填写注册信息 → 验证 → 调用 RegisterUser
  │     ↓ 成功
  │   保存凭据 → 切换登录表单 → 自动填充 → 等待登录
  │
  └─ 直接登录 → 验证 → 调用 LoginUser
        ↓ 成功
      保存 userInfo → 清除 lastRegisteredUser → 跳转主页
```

## ⚠️ 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 网络失败 | 显示"请求失败" + 错误详情 |
| 用户名已存在 | 注册时提示"用户名已被使用" |
| 邮箱已注册 | 注册时提示"该邮箱已注册" |
| 密码错误 | 登录时提示"用户名或密码错误" |
| 账户禁用 | 登录时提示"账户已被禁用" |
| 数据库错误 | 记录日志 + 显示友好提示 |
