## 🎨 动画元素详解

### 1. **第一道刀光 - 横空出世** ⚡

```css
.sword-slash {
    width: 800px;
    height: 4px;
    background: linear-gradient(
        90deg,
        transparent,
        rgba(139, 115, 85, 0.8),    /* 深棕色刀身 */
        rgba(255, 255, 255, 0.9),   /* 白色刀刃 */
        rgba(139, 115, 85, 0.8),
        transparent
    );
    box-shadow: 
        0 0 30px rgba(139, 115, 85, 0.6),  /* 光晕 */
        0 0 60px rgba(139, 115, 85, 0.4);  /* 远光 */
}
```

#### 动画效果
```css
@keyframes swordSlashAnim {
    0% {
        transform: translateX(-100%) rotate(-15deg);
        opacity: 0;  /* 从左侧屏幕外切入 */
    }
    30% {
        opacity: 1;  /* 完全显现 */
    }
    70% {
        transform: translateX(100vw) rotate(-15deg);
        opacity: 1;  /* 划过屏幕 */
    }
    100% {
        opacity: 0;  /* 右侧消失 */
    }
}
```

**视觉效果：**
- 从左向右快速划过
- 带有 15 度倾斜角，模拟挥刀动作
- 中间亮两边暗，如刀光闪烁
- 持续时间：1.2 秒

---

### 2. **第二道刀光 - 反手一刀** 🔄

```css
.sword-slash-2 {
    width: 600px;
    height: 3px;
    background: linear-gradient(
        90deg,
        transparent,
        rgba(92, 64, 51, 0.9),    /* 更深的棕色 */
        rgba(255, 255, 255, 1),   /* 更亮的刀刃 */
        rgba(92, 64, 51, 0.9),
        transparent
    );
    box-shadow: 0 0 20px rgba(92, 64, 51, 0.8);
    top: 60%;  /* 位置偏下 */
}
```

#### 动画效果
```css
@keyframes swordSlashAnim2 {
    0% {
        transform: translateX(100%) rotate(10deg);
        opacity: 0;  /* 从右侧屏幕外切入 */
    }
    30% {
        opacity: 1;
    }
    70% {
        transform: translateX(-100vw) rotate(10deg);
        opacity: 1;  /* 反向划过 */
    }
    100% {
        opacity: 0;
    }
}
```

**视觉效果：**
- 从右向左反向划过
- 延迟 0.3 秒触发，形成连招
- 倾斜角度相反（+10 度）
- 位置偏下，如同低身位攻击
- 持续时间：1 秒

---

### 3. **剑气特效 - 水墨扩散** 💨

```css
.sword-energy {
    width: 10px;
    height: 10px;
    background: radial-gradient(
        circle,
        rgba(139, 115, 85, 0.8) 0%,  /* 中心深色 */
        transparent 70%               /* 边缘透明 */
    );
    border-radius: 50%;
    filter: blur(3px);  /* 模糊效果 */
}
```

#### 动画效果
```css
@keyframes swordEnergyExpand {
    0% {
        transform: scale(1);
        opacity: 1;
    }
    100% {
        transform: scale(50);  /* 放大 50 倍 */
        opacity: 0;
    }
}
```

**视觉效果：**
- 三个剑气点分布在屏幕不同位置
- 延迟 0.2 秒触发
- 如水墨滴在宣纸上般扩散
- 从实心到透明的渐变消失
- 持续时间：1.5 秒

---

### 4. **文字显现 - 收刀入鞘** ✍️

```css
.sword-text {
    font-size: 48px;
    font-weight: 700;
    color: #5c4033;  /* 深棕色 */
    font-family: "KaiTi", "楷体", serif;
    text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.2);
    letter-spacing: 8px;  /* 字间距加大 */
}
```

#### 动画效果
```css
@keyframes swordTextAppear {
    0% {
        opacity: 0;
        transform: translateY(20px);  /* 从下方浮现 */
    }
    50% {
        opacity: 1;
        transform: translateY(0);  /* 到达中心位置 */
    }
    80% {
        opacity: 1;  /* 保持可见 */
    }
    100% {
        opacity: 0;
        transform: translateY(-20px);  /* 向上飘散消失 */
    }
}
```

**视觉效果：**
- 延迟 1.5 秒后出现
- 从下往上缓缓浮现
- 停留片刻后向上消散
- 如同武侠小说中的招式名称
- 持续时间：2 秒

---

### 5. **刀鞘轮廓 - 纳刀归鞘** 📜

```css
.sword-sheath {
    width: 400px;
    height: 60px;
    border: 3px solid rgba(139, 115, 85, 0.5);
    border-radius: 0 30px 30px 0;  /* 右端圆弧 */
    border-left: none;  /* 左端开口 */
    transform-origin: left;  /* 从左端展开 */
}
```

#### 动画效果
```css
@keyframes sheathAppear {
    0% {
        transform: scaleX(0);  /* 完全收缩 */
        opacity: 0;
    }
    70% {
        transform: scaleX(1);  /* 完全展开 */
        opacity: 1;
    }
    100% {
        transform: scaleX(1);
        opacity: 0;  /* 淡出 */
    }
}
```

**视觉效果：**
- 延迟 2 秒后出现
- 从左向右横向展开
- 如同刀鞘逐渐显现
- 象征收刀入鞘的动作
- 持续时间：0.8 秒

---

### 6. **容器淡出 - 正片开始** 🎭

```css
.sword-intro-container {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: rgba(244, 240, 230, 0.98);  /* 半透明宣纸色 */
    z-index: 9999;  /* 最顶层 */
    pointer-events: none;  /* 不阻挡交互 */
}
```

#### 动画效果
```css
@keyframes introFadeOut {
    to {
        opacity: 0;
        visibility: hidden;  /* 完全隐藏 */
    }
}
```

**视觉效果：**
- 延迟 2.8 秒后开始淡出
- 0.8 秒内完全消失
- 露出下方的编辑器界面
- 完成转场

## 💡 设计理念

### 1. **动静结合**

- **动**：刀光快速闪过（1.2 秒）
- **静**：文字缓慢显现（2 秒）
- **节奏感**：快慢交替，张弛有度

### 2. **虚实相生**

- **实**：刀光实体（具体形状）
- **虚**：剑气扩散（模糊渐变）
- **层次感**：虚实结合，意境深远

### 3. **古今融合**

- **古**：武侠文化、水墨元素
- **今**：CSS 动画、现代技术
- **创新**：传统文化现代表达

### 4. **形神兼备**

- **形**：视觉效果精美
- **神**：文化内涵深厚
- **统一**：形式服务于内容

## 🔧 技术实现要点

### 1. **层级管理**

```css
z-index: 9999;  /* 最高层 */
pointer-events: none;  /* 不阻挡交互 */
```

- 确保动画在最上层
- 但不影响用户提前操作

### 2. **性能优化**

```css
transform: translateX(...) rotate(...);  /* GPU 加速 */
opacity: ...;  /* 合成器友好 */
```

- 使用 transform 而非 margin/padding
- 避免触发布局重排
- 60fps 流畅运行

### 3. **时间控制**

```css
animation: ... 2.8s forwards;  /* 精确计时 */
animation-delay: 0.3s;  /* 延迟触发 */
```

- 精确控制每个元素的出场时机
- 形成连贯的叙事节奏

### 4. **兼容性**

```css
font-family: "KaiTi", "楷体", "STKaiti", "SimSun", serif;
```

- 提供多个字体备选
- 确保跨平台显示正常
