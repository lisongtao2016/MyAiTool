## 2. 表结构定义 (Schema)

### 2.1 用户表 (`Users`)
存储账号核心信息。

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| **Id** | INTEGER | PK, AI | 唯一自增 ID |
| **Username** | VARCHAR(50) | NOT NULL, UNIQUE | 登录用户名 |
| **Email** | VARCHAR(255) | NOT NULL, UNIQUE | 注册邮箱 |
| **PhoneNumber** | VARCHAR(20) | UNIQUE | 手机号 (可为空) |
| **PasswordHash** | VARCHAR(255) | NOT NULL | 存储 BCrypt 等算法的哈希值 |
| **DisplayName** | VARCHAR(100) | - | 用户昵称 |
| **AvatarUrl** | VARCHAR(500) | - | 头像图片链接 |
| **IsActive** | BOOLEAN | DEFAULT 1 | 账户状态 (1:正常, 0:禁用) |
| **CreatedDate** | DATETIME | DEFAULT CURRENT_TIMESTAMP | 注册时间 |
| **UpdatedDate** | DATETIME | DEFAULT CURRENT_TIMESTAMP | 最后修改时间 |

### 2.2 角色表 (`Roles`)
定义系统权限组。

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| **Id** | INTEGER | PK, AI | 角色 ID |
| **RoleName** | VARCHAR(50) | NOT NULL | 角色中文名 (如: 管理员) |
| **RoleKey** | VARCHAR(50) | NOT NULL, UNIQUE | 角色标识符 (如: admin) |
| **Description** | VARCHAR(255) | - | 角色职能描述 |

### 2.3 权限表 (`Permissions`)
定义最细颗粒度的功能点。

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| **Id** | INTEGER | PK, AI | 权限 ID |
| **PermName** | VARCHAR(50) | NOT NULL | 权限显示名称 |
| **PermKey** | VARCHAR(100) | NOT NULL, UNIQUE | 权限字符串 (如: sys:user:add) |
| **ParentId** | INTEGER | DEFAULT 0 | 父权限 ID (用于树状菜单) |

### 2.4 关联表 (Junction Tables)
* **UserRoles**: 映射用户与角色的多对多关系。
* **RolePermissions**: 映射角色与权限的多对多关系。

## 3. 示例数据 (Seed Data)

### 3.1 权限与角色初始化
```sql
-- 权限项
INSERT INTO Permissions (Id, PermName, PermKey, ParentId) VALUES 
(1, '用户管理', 'sys:user:view', 0),
(2, '删除用户', 'sys:user:delete', 1),
(3, '文章管理', 'content:post:view', 0),
(4, '发布文章', 'content:post:create', 3);

-- 角色项
INSERT INTO Roles (Id, RoleName, RoleKey, Description) VALUES 
(1, '超级管理员', 'admin', '全系统权限'),
(2, '内容编辑', 'editor', '负责内容运营');
```

### 3.2 用户登录与关联数据
以下为三个典型用户的初始状态：

| 用户名 (Username) | 昵称 (DisplayName) | 角色 (Role) | 权限概览 |
| :--- | :--- | :--- | :--- |
| **admin_zero** | 首席管理员 | 超级管理员 | 拥有 `sys:*` 和 `content:*` 所有权限 |
| **writer_jane** | 资深编辑 | 内容编辑 | 仅拥有文章查看与发布权限 |
| **lucky_dog** | 普通路人 | (无角色) | 仅能基础登录，无管理权限 |

```sql
-- 插入用户
INSERT INTO Users (Id, Username, Email, PasswordHash, DisplayName) VALUES 
(1, 'admin_zero', 'admin@test.com', '$2b$12$K8...', '首席管理员'),
(2, 'writer_jane', 'jane@test.com', '$2b$12$L9...', '资深编辑');

-- 绑定角色
INSERT INTO UserRoles (UserId, RoleId) VALUES (1, 1); -- admin -> 超级管理员
INSERT INTO UserRoles (UserId, RoleId) VALUES (2, 2); -- jane -> 内容编辑

-- 角色授权
INSERT INTO RolePermissions (RoleId, PermissionId) VALUES (1, 1), (1, 2), (1, 3), (1, 4); -- 管理员全开
INSERT INTO RolePermissions (RoleId, PermissionId) VALUES (2, 3), (2, 4); -- 编辑仅看/发文章
```

## 4. 自动化脚本 (SQL)

```sql
-- 触发器：自动更新 UpdatedDate 字段
CREATE TRIGGER tr_Users_UpdateTimestamp
AFTER UPDATE ON Users
FOR EACH ROW
BEGIN
    UPDATE Users SET UpdatedDate = CURRENT_TIMESTAMP WHERE Id = OLD.Id;
END;
```

## 5. 核心查询示例
**场景：用户登录后获取其拥有的所有权限 Key**
```sql
SELECT DISTINCT p.PermKey 
FROM Permissions p
JOIN RolePermissions rp ON p.Id = rp.PermissionId
JOIN UserRoles ur ON rp.RoleId = ur.RoleId
WHERE ur.UserId = 1; -- 替换为当前登录用户的 Id
```
