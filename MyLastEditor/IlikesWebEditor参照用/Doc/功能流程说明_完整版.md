# MyLastEditor 功能流程说明

---

## 一、页面加载流程

### 打开页面时执行：
```
1. 初始化数据库（如果不存在则创建）
2. 初始化 ACE 编辑器
3. 加载编程语言列表
4. 设置默认语言为 JavaScript
5. 显示空白的编辑界面
```

---

## 二、保存内容流程

### 点击「保存内容」按钮时：

**情况 1：新建模式（未加载任何内容）**
```
1. 验证必填字段（标题、内容、语言）
2. 收集所有表单数据
3. 发送 AJAX 请求到后端 SaveContent 方法
4. 后端创建新记录，保存到数据库
5. 返回新记录的 ID
6. 前端提示："内容保存成功！ID: xxx"
7. 清空所有输入框
8. 重新加载内容列表
```

**情况 2：更新模式（已加载某条内容）**
```
1. 验证必填字段（标题、内容、语言）
2. 收集所有表单数据 + 当前编辑的 ID
3. 发送 AJAX 请求到后端 SaveContent 方法
4. 后端根据 ID 找到原记录
5. 更新原记录的所有字段
6. 返回更新的 ID
7. 前端提示："内容更新成功！ID: xxx"
8. 清空所有输入框
9. 重置编辑状态（currentEditingId = null）
10. 重新加载内容列表
```

---

## 三、加载内容流程

### 点击「加载列表」按钮时：
```
1. 发送 AJAX 请求到后端 GetAllContents 方法
2. 后端查询所有内容，按创建时间倒序排列
3. 返回内容列表（JSON 格式）
4. 前端解析 JSON 数据
5. 生成 HTML 表格，显示所有记录
6. 绑定「加载」和「删除」按钮事件
```

### 点击某条记录的「加载」按钮时：
```
1. 获取该记录的 ID
2. 发送 AJAX 请求到后端 LoadContent 方法
3. 后端根据 ID 查询单条记录
4. 返回完整的记录数据（JSON 格式）
5. 前端解析 JSON 数据
6. 填充所有表单字段：
   - 标题 → #contentTitle
   - 副标题 → #contentSubtitle
   - 作者 → #contentAuthor
   - 热门标签 → #contentHotTags
   - 分享给 → #contentShareTo
   - 语言 → #languageSelect
   - 代码内容 → 编辑器
7. 记录当前编辑的 ID（currentEditingId = 内容 ID）
8. 提示："内容加载成功！"
```

---

## 四、删除内容流程

### 点击某条记录的「删除」按钮时：
```
1. 弹出确认对话框："确定要删除这个内容吗？"
2. 用户确认后，获取该记录的 ID
3. 发送 AJAX 请求到后端 DeleteContent 方法
4. 后端根据 ID 删除记录
5. 返回成功消息
6. 前端重新加载内容列表
7. 提示："内容删除成功！"
```

---

## 五、关键状态管理

### currentEditingId 变量

| 值 | 含义 | 保存时的行为 |
|----|------|-------------|
| `null` | 新建模式 | 创建新记录 |
| `数字` | 更新模式 | 更新该 ID 的记录 |

**状态变化：**
```
页面加载 → currentEditingId = null（新建模式）
加载内容 → currentEditingId = 内容 ID（更新模式）
保存成功 → currentEditingId = null（回到新建模式）
```

## 六、数据流向图

```
前端（浏览器）                    后端（服务器）
─────────────                    ─────────────

[保存内容]
   │
   ├─→ 收集表单数据
   │
   ├─→ AJAX POST ───────────────→ SaveContent 方法
   │                               │
   │                               ├─→ 判断是否有 ID
   │                               │   ├─ 有 ID → UpdateContent
   │                               │   └─ 无 ID → InsertContent
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {success: true, id: 123}
   │
   └─→ 显示提示 + 清空表单


[加载内容]
   │
   ├─→ 获取内容 ID
   │
   ├─→ AJAX POST ───────────────→ LoadContent 方法
   │                               │
   │                               ├─→ 查询数据库
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {title, content, ...}
   │
   └─→ 填充表单 + 设置编辑器


[删除内容]
   │
   ├─→ 获取内容 ID
   │
   ├─→ AJAX POST ───────────────→ DeleteContent 方法
   │                               │
   │                               ├─→ 删除记录
   │                               │
   │←────── 返回 JSON ────────────┘
   │    {success: true}
   │
   └─→ 刷新列表
```

## 七、核心文件职责

| 文件 | 职责 |
|------|------|
| **WebForm1.aspx** | 主页面，包含所有 UI 元素 |
| **EditorContentManager.js** | 处理保存、加载、删除的 JavaScript 逻辑 |
| **EditorPage.js** | 初始化编辑器和语言选择器 |
| **WebForm1.aspx.cs** | 后端 WebMethod 接口（SaveContent、LoadContent 等） |
| **EditorContent.cs** | 数据模型定义（EditorContent 类） |
| **EditorContentRepository.cs** | 数据库 CRUD 操作 |
| **InitializeDatabase.cs** | 数据库初始化 |

---

## 八、一句话总结

**页面加载** → 初始化一切  
**点击保存** → 判断是新建还是更新  
**点击加载** → 从数据库取数据并填充  
**点击删除** → 从数据库删除记录  

**关键机制**：通过 `currentEditingId` 变量区分新建和更新

## 九、待扩展功能建议

### 高优先级（立即实现）

#### 1. 搜索/过滤功能 ⭐⭐⭐⭐⭐
```
理由：随着保存的内容增多，查找特定代码会很困难

功能描述：
- 按标题搜索
- 按标签搜索  
- 按语言过滤
- 按作者搜索

实现方式：
在"加载列表"按钮上方添加一个搜索框
修改 displayContentList 函数，增加过滤逻辑
```

#### 2. 内容预览/详情查看 ⭐⭐⭐⭐
```
理由：现在只能全部加载到编辑器才能看内容，不够直观

功能描述：
- 点击列表项显示简要预览
- 弹窗显示完整内容（只读）
- 不需要填充到表单

实现方式：
在列表中增加"查看"按钮
点击后弹出模态框显示内容
```

#### 3. 导出功能 ⭐⭐⭐⭐
```
理由：方便备份和分享代码片段

功能描述：
- 导出单条内容为 .txt 或 .code 文件
- 导出所有内容为 ZIP 包
- 选择多条记录批量导出

实现方式：
添加"导出"按钮
后端生成文件下载链接
```

#### 4. 自动保存草稿 ⭐⭐⭐
```
理由：防止意外关闭浏览器丢失内容

功能描述：
- 定时保存到 localStorage（如每 30 秒）
- 刷新页面后恢复草稿
- 手动清除草稿

实现方式：
使用 localStorage 临时存储
setInterval 定时保存
页面加载时检查是否有草稿
```

### 中优先级（后续实现）

#### 5. 排序功能 ⭐⭐⭐
```
理由：可以按不同维度查看内容

功能描述：
- 按创建时间排序（最新/最旧）
- 按标题字母排序
- 按语言分组

实现方式：
在列表上方添加排序下拉框
修改 GetAllContents 的 SQL 查询顺序
```

#### 6. 最近访问记录 ⭐⭐⭐
```
理由：快速找到最近使用的代码

功能描述：
- 记录每次加载的内容 ID
- 显示"最近访问"列表（最多 10 条）
- 快速重新加载

实现方式：
使用 localStorage 存储访问历史
在页面侧边显示最近访问面板
```

### 低优先级（可选）

#### 7. 批量操作 ⭐⭐
```
理由：一次删除多条记录会更方便

功能描述：
- 列表前加复选框
- 批量删除选中项
- 批量导出代码文件

实现方式：
修改 displayContentList 函数，添加复选框
添加"批量删除"按钮
```

#### 8. 代码统计信息 ⭐⭐
```
理由：了解自己的代码库规模

功能描述：
- 显示已保存多少条记录

实现方式：

```
