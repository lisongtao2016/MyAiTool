# 🌃 赛博朋克风界面 - 左侧边栏设计

## 🎨 设计理念

融合**赛博朋克 2077**风格与现代化 UI 设计，打造未来感十足的代码编辑器界面。

## ✨ 核心特性

### 1. **左侧边栏布局**
```
┌─────────────────────────────────────┐
│ 侧边栏 (350px) │  主内容区          │
│ ┌───────────┐  │                   │
│ │ 📚 代码库  │  │  💻 编辑器        │

│ │ 🔍 搜索框  │  │  📝 标题/内容     │

│ └───────────┘  │                   │
```

### 2. **收缩/展开功能**
- **展开宽度**: 350px

- **动画过渡**: 0.3s 平滑过渡
- **切换按钮**: 右上角 ◀ 图标

### 3. **实时搜索功能**
- **搜索范围**: 标题、副标题、作者、热门标签
- **即时过滤**: 输入时实时筛选
- **高亮显示**: 匹配项清晰可见
- **空状态提示**: "未找到匹配的内容"

## 🔧 功能实现

### HTML 结构
```html
<div class="container">
    <!-- 左侧边栏 -->
    <div class="sidebar">
        <div class="sidebar-header">
            <span>📚 代码库</span>
            <button id="btnToggleSidebar">◀</button>
        </div>
        <div class="search-container">
            <input type="text" id="searchBox" placeholder="🔍 搜索标题..." />
        </div>
        <button id="btnLoadList">📋 刷新列表</button>
        <div id="contentList"></div>
    </div>
    
    <!-- 右侧主内容区 -->
    <div class="main-content">
        <!-- 语言选择、表单、编辑器 -->
    </div>
</div>
```

### CSS 关键样式
```css
/* Flexbox 布局 */
.container {
    display: flex;
    min-height: calc(100vh - 40px);
}

/* 侧边栏 */
.sidebar {
    width: 350px;
    transition: all 0.3s ease;
}

.sidebar.collapsed {
    width: 60px;
}

/* 搜索框 */
.search-box {
    width: 100%;
    border: 2px solid #00ffff;
    color: #00ff00;
}

.search-box:focus {
    border-color: #ffff00;
    box-shadow: 0 0 20px rgba(255, 255, 0, 0.6);
}
```

### JavaScript 逻辑
```javascript
// 全局变量
var allContents = []; // 存储所有内容用于搜索

// 侧边栏切换
$('#btnToggleSidebar').click(toggleSidebar);
function toggleSidebar() {
    $('.sidebar').toggleClass('collapsed');
}

// 搜索功能
$('#searchBox').on('input', function() {
    var searchText = $(this).val().toLowerCase();
    filterContentList(searchText);
});

// 搜索过滤
function filterContentList(searchText) {
    if (!searchText) {
        renderContentTable(allContents);
        return;
    }
    
    var filtered = allContents.filter(function(content) {
        return content.title.toLowerCase().includes(searchText) ||
               (content.subtitle && content.subtitle.toLowerCase().includes(searchText)) ||
               (content.author && content.author.toLowerCase().includes(searchText)) ||
               (content.hotTags && content.hotTags.toLowerCase().includes(searchText));
    });
    
    renderContentTable(filtered);
}
```

## 🚀 使用指南

### 第一次打开
1. 页面加载，侧边栏默认展开
2. 点击"📋 刷新列表"加载内容
3. 列表显示在左侧边栏

### 搜索内容
1. 在搜索框中输入关键字
2. 列表实时过滤显示
3. 清空搜索框恢复完整列表

### 收缩侧边栏
1. 点击右上角 ◀ 按钮
2. 侧边栏收缩到 60px
3. 再次点击展开

### 加载内容
1. 点击列表中的"加载"按钮
2. 内容填充到右侧编辑区
3. 可修改后点击"保存内容"
