# 🗡️ SVG 剑客人物设计说明

## 🎨 设计理念

> **"身如松柏，势如破竹"**

用水墨画风格绘制一位古代剑客，展现武侠文化的精髓。

---

## 👤 人物造型

### 整体风格
- **水墨写意**：不求形似，但求神似
- **简练概括**：用最少的线条表达最多的意境
- **色彩古朴**：深棕、浅棕、墨黑为主色调
- **动感十足**：挥刀姿势，蓄势待发

---

## 🎭 动画系统

### 1. **整体淡入** (0.3-1.1 秒)

```css
.swordsman-body {
    animation: swordsmanAppear 0.8s ease 0.3s forwards;
}

@keyframes swordsmanAppear {
    from {
        opacity: 0;
        transform: scale(0.9);
    }
    to {
        opacity: 1;
        transform: scale(1);
    }
}
```

**效果：**
- 延迟 0.3 秒出现
- 从 90% 大小放大到 100%
- 同时透明度从 0 到 1

---

### 2. **手臂挥刀** (0.5-2.3 秒)

```css
.swordsman-arm {
    transform-origin: 180px 220px;  /* 肩部为轴心 */
    animation: armSlash 1.8s cubic-bezier(0.4, 0, 0.2, 1) 0.5s forwards;
}

@keyframes armSlash {
    0%, 10% {
        transform: rotate(-30deg);   /* 起始位置 */
    }
    50% {
        transform: rotate(60deg);    /* 挥刀到最高点 */
    }
    100% {
        transform: rotate(-10deg);   /* 收刀位置 */
    }
}
```

**效果：**
- 延迟 0.5 秒开始
- 先向后蓄力（-30 度）
- 快速挥出（60 度）
- 最后收刀（-10 度）

---

### 3. **呼吸效果** (持续)

```css
.swordsman-torso {
    animation: bodyBreathe 2s ease-in-out infinite 1s;
}

@keyframes bodyBreathe {
    0%, 100% {
        transform: scaleY(1);
    }
    50% {
        transform: scaleY(1.02);
    }
}
```

**效果：**
- 延迟 1 秒后开始
- 2 秒一个循环
- Y 轴缩放±2%，模拟呼吸
- 无限循环

## 💡 设计巧思

### 1. **动静结合**

**动：**
- 手臂挥刀（大动作）
- 身体呼吸（微动作）

**静：**
- 头部稳定
- 腿部稳固

**效果：** 既有动感，又不失稳重

---

### 2. **虚实相生**

**实：**
- 身体主体（不透明度 0.85-0.9）

**虚：**
- 衣襟（不透明度 0.7）
- 左臂（不透明度 0.7）

**效果：** 层次分明，空间感强

---

### 3. **色彩呼应**

**棕色系统一：**
- 头发 → 裤子 → 腰带（#3a2818）
- 头部 → 手部 → 刀柄（#5c4033）
- 手臂 → 衣服（#8b7355）

**对比色点缀：**
- 玉佩蓝色（#1e90ff）打破单调
- 刀刃白色（#ffffff）提亮画面

---

### 4. **文化符号**

**汉服元素：**
- 交领右衽
- 宽袍大袖
- 腰系玉带

**武侠元素：**
- 发髻（古代武者发型）
- 长刀（兵器）
- 玉佩（君子如玉）

## 🎬 与整体动画的配合

### 时间轴配合

```
0s     0.3s    0.5s           1.8s    2.3s    3.2s    4.0s
│──────│───────│──────────────│───────│───────│───────│
       剑客    手臂    刀光 1     刀光 2   文字    淡出
       出现    挥刀    剑气      跟进   显现    刀鞘
               呼吸↺            消失
```

### 节奏配合

**剑客出现 (0.3s)**
↓
**第一道刀光 (0s 启动)**
↓
**手臂挥刀 (0.5s)** ← 与刀光同步
↓
**第二道刀光 (0.5s)** ← 与挥刀顶点同步
↓
**文字显现 (1.8s)** ← 收刀时出现
