## 📋 完整测试场景

### 场景 1：新建第一条内容
```
步骤：
1. 打开页面
2. 输入标题："测试内容 1"
3. 选择语言：JavaScript
4. 输入内容：console.log("Hello");
5. 点击"保存内容"

预期结果：
- 提示："内容保存成功！ID: 1"
- 表单清空
- 数据库中有 1 条记录
```

### 场景 2：修改已有内容
```
步骤：
1. 点击"加载列表"
2. 点击 ID=1 的"加载"按钮
3. 修改标题为："测试内容 1 - 已修改"
4. 修改内容为：console.log("World");
5. 点击"保存内容"

预期结果：
- 提示："内容更新成功！ID: 1"
- 表单清空
- 数据库中仍然是 1 条记录（不是 2 条）
- 该记录的内容已被更新
```

### 场景 3：连续新建多条内容
```
步骤：
1. 保存第一条内容后
2. 不加载任何内容
3. 直接输入新的标题和内容
4. 点击"保存内容"
5. 重复上述步骤

预期结果：
- 每次都创建新记录
- 提示都是"内容保存成功！ID: xxx"
- 数据库中有多条独立记录
```

### 场景 4：加载后取消编辑
```
步骤：
1. 加载某条内容（currentEditingId = 1）
2. 不做任何修改
3. 清空表单手动输入新内容
4. 点击"保存内容"

预期结果：
- 应该创建新记录（因为表单已清空）
- 提示"内容保存成功！ID: xxx"
- 原记录未被修改
```

### 场景 5：删除操作
```
步骤：
1. 假设有 3 条记录（ID=1,2,3）
2. 点击 ID=2 的"删除"按钮
3. 确认删除

预期结果：
- 提示"内容删除成功！"
- 列表中只剩 ID=1 和 ID=3
- 数据库中 ID=2 的记录被删除
```

## 🐛 常见问题排查

### 问题 1：保存后总是创建新记录
**检查点：**
- currentEditingId 是否正确设置？
- 加载内容时是否设置了 currentEditingId？
- SaveContent 方法的 id 参数是否正确传递？

**调试方法：**
在浏览器控制台查看：
```javascript
console.log('当前编辑 ID:', currentEditingId);
```

### 问题 2：加载后又变回初始状态
**检查点：**
- 按钮是否有 type="button"？
- 是否触发了表单提交？
- allowAutoExample 标志是否正确工作？

**调试方法：**
查看控制台日志，确认没有页面刷新

### 问题 3：更新提示信息不对
**检查点：**
- 是否正确判断了 currentEditingId？
- 提示消息是"保存成功"还是"更新成功"？

**预期行为：**
- currentEditingId 为 null → "内容保存成功！"
- currentEditingId 有值 → "内容更新成功！"

## ✅ 验收标准

### 必须通过的核心测试
1. ✅ 能够新建内容
2. ✅ 能够加载内容
3. ✅ 加载后修改再保存，能够更新原记录（不创建新记录）
4. ✅ 能够删除内容
5. ✅ 状态管理正确（currentEditingId 的变化符合预期）

### 性能要求
- 保存操作响应时间 < 2 秒
- 加载列表响应时间 < 2 秒
- 删除操作响应时间 < 1 秒

### 用户体验要求
- 操作前必须有明确的提示
- 保存/加载/删除时必须显示状态（如"保存中..."）
- 错误信息必须清晰易懂
