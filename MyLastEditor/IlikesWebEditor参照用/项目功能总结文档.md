# IlikesWebEditor 项目功能总结文档

## 项目概述
**IlikesWebEditor** 是一个基于 ASP.NET WebForm + SQLite + JavaScript 的 Web 文本编辑器，核心设计理念是**每个文章都有明确的归属**：属于特定用户、可归属于特定项目。

## 核心设计理念
- **用户为中心**：每个操作都与用户身份绑定
- **项目化管理**：文章可以按项目分组，实现内容组织
- **完整归属链**：User → Project → EditorContent 三层归属关系

## 🔗 归属关系实现

### 1. 文章属于用户
**实现方式**：`EditorContent.Author` 字段存储用户名
- 每篇文章保存时记录作者
- 通过作者字段可以追溯文章创建者
- 与 Users 表的 Username 字段关联

### 2. 文章属于项目
**实现方式**：`EditorContent.ProjectId` 字段存储项目ID
- 可为 NULL，表示文章不属于任何项目
- 非 NULL 时，关联到 Projects 表的 Id
- 支持按项目筛选文章：`GetContentsByProject(int? projectId)`

### 3. 项目属于用户
**实现方式**：`Project.CreatedBy` 字段存储用户名
- 每个项目记录创建者
- 实现用户对项目的所有权

### 4. 完整的归属链
```
用户 (Users)
  ↓ (CreatedBy)
项目 (Projects)
  ↓ (ProjectId)
文章 (EditorContents)
  ↑ (Author)
用户 (Users)
```

**循环归属关系**：
- 用户创建项目
- 用户在项目中创建文章
- 文章记录作者（用户）
- 形成完整的归属和追溯链条

## 🎯 核心使用场景

### 场景1：用户创建项目并添加文章
1. 用户注册/登录系统
2. 创建新项目（例如"Web开发笔记"）
3. 在项目下创建新文章（例如"HTML基础教程"）
4. 文章自动记录作者和项目归属

### 场景2：按项目查看文章
1. 用户选择特定项目
2. 系统显示该项目下的所有文章
3. 可按时间、语言、标签等进一步筛选

### 场景3：搜索个人文章
1. 用户登录后，搜索关键词"JavaScript"
2. 系统在所有自己的文章中搜索
3. 结果显示文章内容、所属项目和创建时间

### 场景4：文章迁移
- 文章可从一个项目移动到另一个项目（通过更新ProjectId）
- 文章可设置为不属于任何项目（ProjectId = NULL）
