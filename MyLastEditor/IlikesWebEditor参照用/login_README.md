# 登录页面 (login.html)

## 📋 功能概述

IlikesWebEditor 的用户认证入口页面，提供用户登录和注册功能。

---

## ✨ 核心功能

### 1. **用户登录**
- 支持用户名或邮箱登录
- 密码验证（SHA256 哈希）
- 自动跳转到主编辑器页面
- 保存用户信息到 localStorage

### 2. **用户注册**
- 必填字段：用户名、邮箱、密码
- 可选字段：显示名称
- 表单验证：
  - 用户名长度：3-20 个字符
  - 邮箱格式验证
  - 密码最少 6 个字符
  - 两次密码一致性检查

### 3. **智能填充**
- **注册后自动填充**：注册成功后自动返回登录页并填充凭据
- **再次访问自动填充**：从 localStorage 读取上次注册的凭据
- **不自动登录**：让用户确认后再点击登录按钮

### 4. **用户体验优化**
- 渐变背景和现代化 UI 设计
- 加载状态动画
- 错误/成功消息提示
- 脉冲动画引导用户操作
- 回车键快速提交

## 🔧 技术实现

### 前端技术
- **jQuery 4.0.0**：DOM 操作和 AJAX
- **AJAX 调用**：与后端 WebServ.asmx 通信
- **localStorage**：持久化存储用户凭据

### 后端接口
- `WebServ.asmx/LoginUser` - 用户登录
- `WebServ.asmx/RegisterUser` - 用户注册

### 数据存储
- **SQLite 数据库**：Users 表
- **密码加密**：SHA256 哈希
- **本地存储**：
  - `userInfo` - 当前登录用户信息
  - `lastRegisteredUser` - 上次注册的凭据

## 🎯 使用流程

### 新用户注册
```
1. 点击"立即注册"链接
2. 填写注册表单
3. 点击"注册"按钮
4. 自动返回登录页并填充凭据
5. 点击"登录"完成登录
```

### 已有账户登录
```
1. 输入用户名/邮箱和密码
   （或等待自动填充）
2. 点击"登录"按钮
3. 自动跳转到 WebForm1.aspx
```

## 📝 注意事项

1. **首次使用**：需要先注册用户才能登录
2. **浏览器缓存**：修改代码后需硬刷新（Ctrl+Shift+R）
3. **会话管理**：登录信息保存在 localStorage，清除浏览器数据会退出
4. **自动跳转**：如果检测到已登录，会自动跳转到主页面
