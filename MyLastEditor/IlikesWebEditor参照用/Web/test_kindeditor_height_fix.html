KindEditor 高度调整问题测试与修复

问题分析

test_bottom_editor.html 中的 KindEditor 可以调整高度，但 WebForm1.aspx 中的 KindEditor（通过 iframe 加载）不能调整高度。

根本原因：在 iframe 环境中，KindEditor 的 height: '100%' 设置可能无法正确计算，因为 iframe 的父容器可能有 CSS 限制或 flexbox 布局问题。

测试 1：直接初始化（工作正常）

直接初始化编辑器

这是 test_bottom_editor.html 的方式：直接创建 KindEditor 实例。

代码示例

KindEditor.create('#directKindEditor', {
    width: '100%',
    height: '100%',
    resizeType: 2
});
测试 2：iframe 中初始化（问题重现）

当前 iframe 实现

这是 kindeditor_iframe.html 的方式：在 iframe 中初始化。

修复后的 iframe 实现

使用改进的高度计算方法。

修复方案

解决方案：

  1. 确保 iframe 的父容器有明确的高度设置
  2. 在 KindEditor 初始化后，动态计算可用高度
  3. 使用 resizeType: 2 启用调整大小功能
  4. 为 iframe 添加 resize 事件监听器
