#### 表结构
```sql
projects (项目表)
├── id (主键)
├── name (项目名称)
└── created_at (创建时间)

tasks (任务表)
├── id (主键)
├── project_id (外键 → projects.id)
├── group_name (项目分组)
├── sub_group (子模块)
├── name (任务名称)
├── start_date (开始日期)
├── end_date (结束日期)
├── start_day (甘特图偏移量)
├── duration (持续时间)
├── plan (计划进度 %)
├── actual (实际进度 %)
├── owner (负责人)
├── created_at (创建时间)
└── updated_at (更新时间)
```
