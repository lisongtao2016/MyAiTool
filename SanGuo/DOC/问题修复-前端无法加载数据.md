# 前端无法加载数据问题 - 修复报告

## 📅 修复日期
2026年4月8日

## ❌ 问题描述
用户打开 `richengbiao.html` 时收到错误提示：
> "无法加载任务数据，请确保后端服务器正在运行"

## 🔍 根本原因

### 1. 端口配置不一致
- **前端配置**: `http://localhost:3001/api`
- **后端实际**: `http://localhost:5288` (launchSettings.json)
- **结果**: 前端请求发送到错误的端口，连接被拒绝

### 2. 数据库路径错误
- **原配置**: `../../schedule.db`
- **实际位置**: `../../data/schedule.db`
- **结果**: 后端启动时找不到数据库文件

## ✅ 修复内容

### 1. 统一端口配置

**文件**: `ScheduleApi/Properties/launchSettings.json`

```json
{
  "profiles": {
    "http": {
      "applicationUrl": "http://localhost:3001",  // 从 5288 改为 3001
      "launchBrowser": false,                      // 禁用自动打开浏览器
      "launchUrl": ""
    }
  }
}
```

**影响**: 
- ✅ 前后端端口现在一致（3001）
- ✅ 避免启动时自动打开 Swagger 页面

### 2. 修复数据库路径

**文件**: `ScheduleApi/Program.cs`

```csharp
static string GetConnectionString()
{
    var currentDir = Directory.GetCurrentDirectory();
    var dbPath = Path.Combine(currentDir, "..", "..", "data", "schedule.db");
    var fullPath = Path.GetFullPath(dbPath);
    
    // 智能路径查找（多备用方案）
    if (!File.Exists(fullPath))
    {
        // 尝试当前目录
        var altPath = Path.Combine(currentDir, "schedule.db");
        if (File.Exists(altPath)) fullPath = altPath;
        else
        {
            // 尝试项目根目录
            var rootPath = Path.Combine(currentDir, "..", "..", "..", "data", "schedule.db");
            fullPath = Path.GetFullPath(rootPath);
        }
    }
    
    Console.WriteLine($"Database path: {fullPath}");
    Console.WriteLine($"Database exists: {File.Exists(fullPath)}");
    
    return $"Data Source={fullPath}";
}
```

**改进**:
- ✅ 主路径指向正确的 `data/schedule.db`
- ✅ 添加调试日志（显示路径和存在状态）
- ✅ 多个备用路径，提高容错性

## ⚠️ 注意事项

1. **首次运行必须初始化数据库**
   ```bash
   sqlite3 data/schedule.db ".read data/schema.sql"
   ```

2. **确保 .NET SDK 已安装**
   ```bash
   dotnet --version
   ```

3. **防火墙设置**
   - 允许端口 3001 入站连接
   - 或仅使用 localhost（默认配置）

4. **不要同时运行多个实例**
   - 会导致端口冲突
   - 诊断脚本会自动检测并提示
