# 日程表系统 - 快速启动指南

## 📋 前置要求

1. **.NET 8.0 SDK** 或更高版本
   - 下载地址: https://dotnet.microsoft.com/download
   - 验证安装: `dotnet --version`

2. **现代浏览器** (Chrome/Edge/Firefox)
   - 支持 ES6+ 和 HTML5 Canvas

3. **SQLite** (可选，用于手动管理数据库)
   - 通常随 .NET 自动包含

## 🚀 快速启动

### 步骤 1: 初始化数据库（首次运行）

```bash
# 在项目根目录执行
sqlite3 data/schedule.db ".read data/schema.sql"
```

或者使用 PowerShell:
```powershell
# Windows PowerShell
cd data
sqlite3 schedule.db ".read schema.sql"
```

### 步骤 2: 启动后端服务器

```bash
# 进入 ScheduleApi 目录
cd ScheduleApi

# 恢复 NuGet 包（首次需要）
dotnet restore

# 运行服务器
dotnet run
```

服务器将在 `http://localhost:3001` 启动

**成功标志**:
```
现在正在监听: http://localhost:3001
应用已启动。按 Ctrl+C 关闭。
```

### 步骤 3: 打开前端界面

#### 方式 A: 直接打开文件
- 主界面: 双击 `src/frontend/richengbiao.html`
- 测试页: 双击 `src/frontend/test_schedule_api.html`

#### 方式 B: 使用命令行
```bash
# Windows
start src/frontend/richengbiao.html

# 或打开测试页面
start src/frontend/test_schedule_api.html
```

## 🔧 常见问题

### 问题 1: dotnet restore 失败

**错误信息**: 无法连接到 nuget.org

**解决方案**:
```bash
# 清除 NuGet 缓存
dotnet nuget locals all --clear

# 重试恢复
dotnet restore
```

如果仍然失败，检查网络连接或配置代理。

### 问题 2: 端口 3001 被占用

**错误信息**: Address already in use

**解决方案**:
```bash
# Windows - 查找占用端口的进程
netstat -ano | findstr :3001

# 终止进程（替换 PID 为实际进程ID）
taskkill /PID <PID> /F
```

### 问题 3: 前端无法连接后端

**症状**: 浏览器控制台显示 CORS 错误或网络错误

**解决方案**:
1. 确认后端服务器正在运行
2. 检查 API_BASE_URL 是否为 `http://localhost:3001/api`
3. 确认防火墙未阻止端口 3001

### 问题 4: 数据库文件不存在

**错误信息**: SQLite error - no such table: tasks

**解决方案**:
```bash
# 重新初始化数据库
sqlite3 data/schedule.db ".read data/schema.sql"
```

## 📊 API 端点参考

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | http://localhost:3001/api/tasks | 获取所有任务 |
| GET | http://localhost:3001/api/tasks/search?owner=张三 | 搜索任务 |
| POST | http://localhost:3001/api/tasks | 创建任务 |
| PUT | http://localhost:3001/api/tasks/1 | 更新任务 ID=1 |
| DELETE | http://localhost:3001/api/tasks/1 | 删除任务 ID=1 |
| GET | http://localhost:3001/health | 健康检查 |

## 💡 开发提示

### 热重载（开发模式）
```bash
cd ScheduleApi
dotnet watch run
```
代码修改后自动重启服务器。

### 查看实时日志
后端会在控制台输出所有请求日志，便于调试。

### 数据库查询
```bash
# 查看所有任务
sqlite3 data/schedule.db "SELECT * FROM tasks"

# 查看任务数量
sqlite3 data/schedule.db "SELECT COUNT(*) FROM tasks"

# 按负责人统计
sqlite3 data/schedule.db "SELECT owner, COUNT(*) FROM tasks GROUP BY owner"
```
