## 技术栈更新

### 后端

- **项目位置**: `ScheduleApi/`

- **数据库**: SQLite (使用 Microsoft.Data.Sqlite)

- **技术**: 原生 JavaScript (ES6+)

- **文件位置**: `src/frontend/`

## API 端点

后端运行在 `http://localhost:3001`

- `GET /api/tasks` - 获取所有任务
- `GET /api/tasks/search?owner=张三` - 按负责人搜索
- `PUT /api/tasks/:id` - 更新任务
- `GET /health` - 健康检查

## 启动方式

### 后端
```bash
cd ScheduleApi
dotnet run
```

### 前端
直接打开 `src/frontend/richengbiao.html` 或使用：
```bash
start src/frontend/richengbiao.html
```

## 注意事项

1. **端口一致性**: 前端 API_BASE_URL 已设置为 `http://localhost:3001/api`，与后端一致
2. **数据库路径**: .NET 后端会自动查找 `../../schedule.db`（相对于 bin 目录）
3. **CORS 配置**: 后端已启用 CORS，允许跨域请求
4. **技术栈约束**: 严格遵守 rule.md 中的技术栈要求，禁止引入其他框架
