# 模拟三国 - 战略游戏引擎

## 项目简介
基于 Web 技术的单机大战场策略游戏（SLG），以三国时期为背景。

## 功能特性
- ✅ 300×300 六边形网格地图（90,000格）
- ✅ 格子大小加倍（64px）更清晰
- ✅ 地形系统（平原、森林、河流、山地、关隘）
- ✅ 设施建造系统（农场、市场、兵舍等7种设施）
- ✅ 视口裁剪和平滑缩放（0.5x - 3.0x）
- ✅ 小地图导航
- ✅ 回合制系统
- ✅ 资源管理（金钱、粮草）
- ✅ 存档/读档功能

## 技术栈
- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **UI库**: jQuery 3.x
- **渲染**: Canvas 2D API
- **数据存储**: LocalStorage

## 快速开始

### 1. 打开游戏
直接在浏览器中打开 `index.html` 文件即可。

**推荐方式：**
- 使用 VSCode 的 Live Server 扩展
- 右键 `index.html` → "Open with Live Server"

### 2. 基本操作

#### 地图导航
- **拖拽**: 按住鼠标左键拖动地图
- **缩放**: 鼠标滚轮缩放（0.5x - 3.0x）
- **小地图**: 点击小地图快速跳转

#### 三种模式
1. **查看模式**（默认）
   - 点击格子查看信息
   - 拖拽移动地图

2. **建造模式**
   - 选择要建造的设施
   - 点击地图格子建造
   - 需要消耗金钱

3. **地形编辑模式**
   - 选择地形类型
   - 点击地图格子修改地形

#### 快捷键
- `空格`: 下一回合
- `Ctrl + S`: 保存游戏
- `Ctrl + L`: 加载游戏

## 项目结构
```
Code/
├── index.html          # 主页面
├── css/
│   ├── style.css       # 主样式
│   └── components.css  # 组件样式
├── js/
│   ├── config.js       # 游戏配置
│   ├── utils.js        # 工具函数
│   ├── terrain.js      # 地形系统
│   ├── facility.js     # 设施系统
│   ├── map.js          # 地图核心
│   ├── renderer.js     # 渲染器
│   ├── input.js        # 输入处理
│   ├── minimap.js      # 小地图
│   └── app.js          # 主应用
├── libs/
│   └── jquery.min.js   # jQuery库（需自行添加）
├── data/               # 数据库目录
└── docs/
    └── 地图需求         # 需求文档
```

## 性能优化
- ✅ 视口裁剪：只渲染可见区域
- ✅ Uint8Array：高效存储地形数据
- ✅ Map：快速查找设施
- ✅ 小地图降采样：每2格渲染1次
- ✅ requestAnimationFrame：流畅动画
- ✅ 300×300 优化：比 1000×1000 快 10 倍

1. 需要在 `libs/` 目录放置 `jquery.min.js` 文件

   - 或使用 CDN（修改 index.html）

2. 首次加载会生成随机地形，可能需要几秒钟

3. 建议使用 Chrome 或 Edge 浏览器以获得最佳性能
